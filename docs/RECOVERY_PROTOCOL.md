# 恢复协议 v1

恢复包为 JSON 外壳，格式与 KDF 参数可见，敏感载荷经 Argon2id + AES-GCM 认证加密。载荷包含随机主密钥、vault_id、格式版本、不同 Drive 发现入口；不含长期 OAuth Token。错误密码、篡改或不支持的版本直接拒绝。

云端路径：`VaultPilot/<vault_id>/catalog/<commit_id>.vpc`。每次提交生成独立、不可变的目录归档；不覆盖唯一的 `latest.json`。归档是 ZIP，`control.json` 保存备份库格式、仓库逻辑 ID、当前与历史位置、受主密钥保护的仓库密码、恢复点与维护删除标记；`points/<point_id>.jsonl` 保存各恢复点自己的文件映射、目录元数据和完整快照引用。生成归档和重建文件索引均采用流式处理，不一次把所有文件映射放入内存。

`.vpc` 以 `VPC1\n` 开头，后续为大端 uint32 长度及 AES-256-GCM 认证加密块。明文按最多 1 MiB 分块，块使用独立随机 nonce。读取前必须验证完成证书中记录的整个 `.vpc` 文件 SHA-256；该全文件摘要同时约束块的次序和完整性，单独验证某个块不能证明整个归档完整。

目录提交分三步，默认 `catalog_replicas=2`，不同 Drive 分别计算：

1. 上传 `.vpc` 到所需数量的 Drive，并下载读回，核对整个文件摘要。
2. 将主密钥认证加密的 `<commit_id>.prepare` 写入上述 Drive，读回严格比较加密数据及明文。收据关联 vault ID、commit ID、归档摘要和 Drive 列表。任何必要准备副本失败时，不生成完成证书；单独存在的 `.vpc` 或 `.prepare` 不会被发现流程发布成恢复点。
3. 所有必要准备副本验证后，生成主密钥认证加密的 `<commit_id>.ok` 完成证书，其中包含 `state=committed` 与 `prepared_replicas`。写入并逐份读回确认；所需数量的证书均验证后，任务才报告完整成功。

至少一份 `.ok` 已持久化、其余证书副本失败时，目录已经逻辑提交，可以从可用证书及匹配归档恢复，但尚未达到配置的保护要求。备份会保留可恢复的恢复点并标记 `protection_status=degraded`；任务返回 `partial_failed` / `PROTECTION_DEGRADED`，不会报告完整成功。没有任何完成证书成功时，提交未完成。清理或迁移遇到保护降级时会保留已提交的登记状态，停止后续破坏性操作，避免回滚出与云端相冲突的位置或删除记录。

空白实例导入恢复包后进入 recovery 模式。也可先以 cloud 模式仅初始化本地管理员，授权原账号后验证 `VaultPilot/<vault_id>/connect.vpkey`，使用原备份密码认证库身份与随机主密钥，再原子切换为 recovery 模式；密码不保存在任务或日志中。网页重新授权 OneDrive，显式选择并验证正确 Drive；发现流程只接受格式、vault ID、commit ID、状态与准备数量均匹配的 `.ok`，并核对归档摘要、认证加密及清单内容，再重建 SQLite。当前可验证完成证书副本不足时，重建点标记为保护降级；离线账号的文件范围另行列明。新清单导入 staging run ID，校验文件数与逻辑字节后，在同一事务中发布仓库、恢复点、清单签名与已认证控制目录缓存；失败保留原来已发布的索引并清理暂存。重复发现同一证书复用已认证缓存；新提交复用签名相同的旧点清单，账号变化仍重新映射可用仓库。恢复执行与重建互斥，替换和删除的旧导入索引随发布事务清理。仓库地址由稳定 Drive ID 转换为新节点的 Rclone remote，不要求旧路径、主机名、remote 名称或数据库存在。

文件恢复采用恢复点自己的路径清单。以完整快照 ID 恢复所选条目至受控私有目录，再按 source_id 映射到新目标。覆盖需要显式批准；缺失账号明确报告范围，允许用户选择部分恢复。恢复节点默认不执行备份、清理、迁移。

整仓迁移先验证目标容量、冻结计划及仓库操作、复制完整仓库，并对新位置执行全量读取检查，再提交新位置登记。旧副本不会自动删除。用户另行明确确认清理旧副本后，系统再次全量检查当前位置，并确认所有有效恢复点所引用的快照存在；随后先将旧位置登记为 `verified=false`、`status=cleanup_pending` 并提交目录，使新节点不会再将该旧位置视为可用回退入口。只有登记提交及副本要求满足后才删除旧位置；删除后登记 `status=deleted`，再次提交目录并核对容量。失败时必须依据登记状态重试，不得将已退休或已删除的位置重新声明为已验证。

协议和恢复包需要版本检查，未知版本不能自动覆盖仓库。新增仓库密码通过新提交自动云端登记，离线恢复包无需逐仓重新导出；改变发现入口、密钥或协议时需重新导出并保存恢复包。

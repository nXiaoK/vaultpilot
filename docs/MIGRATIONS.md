# 数据库与迁移

首次启动创建 SQLite schema version 1，启用 WAL、foreign_keys 和 busy_timeout。实体独立表保存单资源 JSON 文档与乐观版本，文件清单、稳定归属、容量预留、日志、幂等请求使用独立索引表。它不是单个 JSON 状态文件。

`schema_migrations` 记录已应用的版本。当前只有 v1；新增版本必须使用显式事务迁移，并在迁移前备份状态目录。应用索引可由认证云端控制目录重建，SQLite 并不是异机恢复的唯一依据。

排他节点文件锁禁止两个进程同时打开同一状态目录。重启后进行中任务标记 interrupted；未完整发布的恢复点不能因发现某个快照而成为完整点。原节点损坏时，使用新目录导入恢复包，重新授权账号并重建索引，不拷贝原数据库。

整仓迁移保留仓库逻辑 ID，复制和验证目标后才提交新的物理位置。原位置保留供观察与回退；源副本清理须作为独立明确的风险操作，不能先删再复制。

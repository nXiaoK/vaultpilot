## 2026-10-11 遗留备份缓存启动清理

上一项权限修复不会自动解除旧版已留下的受限目录。新增启动清理，仅处理缓存入口下 `manifest-dirs-<数字>` 的实际目录，在任何备份任务启动前按父目录到子目录修复为 `0700` 再删除；缓存预算检查仍只读，避免删除其他运行中任务的占位树。

- 非 root 回归预先将旧树根及 `.@#local` 设为 `0000`，确认清理前缓存预算检查报错；调用实际 `Runtime.New` 后旧树消失，缓存检查恢复正常。
- 验证无关缓存、Restic 索引和近似命名目录原样保留；启动后新增的活动占位树不会被预算检查删除；重复启动清理幂等。
- `os.Root` 限制访问范围，符号链接入口跳过，树内符号链接仅随临时树移除，不跟随；外部源目录的权限和文件内容均保持原样。
- 定向竞态测试及 `go test -race ./...` 全套通过（engine 105.500 秒、platform 105.760 秒、store 2.187 秒，process 命中缓存）；`go vet ./...` 和后端构建通过。真实用户 Debian 上的遗留树由更新后的启动流程或管理员执行日志指定目录清理，尚未远程验收。

## 2026-10-11 备份临时目录权限修复

备份目录占位树不再复制源目录权限，始终保持私有的 `0700`，避免源目录依赖其他所有者、组权限或 ACL 时，临时目录无法遍历、后续 `chmod` 失败及缓存无法清理。原始目录权限和修改时间继续进入加密清单，恢复末尾按原值应用。

- 新增真实 Restic 回归，在扫描后注入无所有者执行权限的目录元数据，模拟源通过 ACL 或其他身份可读的情况；修复前非 root 测试复现 `manifest-dirs-…/.@#local/trash/1Panel: permission denied`。
- 修复后验证分片备份、认证目录提交、恢复内容与空目录、原始目录权限和时间戳、源权限不变及临时目录可清理；不需要修改用户源目录权限。
- 真实 Restic 回归、原有单源恢复布局测试、完整引擎包 `go test -race ./internal/engine`（106.802 秒）、`go vet ./internal/engine` 与后端构建通过。此测试使用本地存储，没有在用户 Debian 或真实 OneDrive 上执行。

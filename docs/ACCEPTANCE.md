# 验收计划

结果见 TEST_REPORT.md；未执行的项目不得记为通过。

1. Go 单元与竞态测试：容量公式、事务预留、源路径限制、恢复包认证、特殊字符文件列表、幂等和退出码识别。
2. 本地真实 Restic 闭环：两个独立目录模拟两个存储入口，备份中文/空格/换行文件、空目录、符号链接；修改、删除、重命名后恢复新旧版本并核对 SHA-256。
3. 空白状态目录：导出恢复包，丢弃原 SQLite 和节点文件，重新接入存储、发现加密目录、重建并恢复。验证后来新增的仓库自动发现。
4. 故障：容量不足、Restic 退出码 3、目录读写失败、目录副本不足、取消、重启、恢复冲突、保护恢复点与迁移中断。
5. 网页：初始化、登录、授权向导、计划创建、分配预览、异步任务、分页恢复浏览、恢复包导入导出、维护确认。
6. 真实 OneDrive Personal：至少两个账号；包括 ODCMetadataArchive 错误入口、稳定 ID 去重、Token 刷新重启持久化、429 Retry-After、配额与项目占用对账、空白实例恢复。没有凭据时标记未验证。
7. 规模：10 账号、100 万索引行、5 TB 源规模，记录 RSS、耗时、磁盘和错误；合成索引仅证明数据库行为，不能代替真实云端吞吐。
